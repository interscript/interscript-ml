# Model Card: rababa_arabic

## Model details

- **Name:** `interscript/rababa_arabic`
- **Type:** Character-level transformer (4 layers, 256 dim, 4 heads)
- **Trained from:** distilled from Qwen3.5-4B-Instruct teacher
- **License:** BSD-3-Clause (code and weights)

## Training data

- Tashkeela++ (~2M verses of diacritized Arabic)
- OpenDiacritizer (augmentation set)
- Synthetic labels generated by fine-tuned Qwen3.5-4B teacher

## Intended use

- Diacritization of Modern Standard Arabic text
- Inference in browser via ONNX runtime (~6MB)
- Powering the `var-ara-Arab-Arab-rababa` map in interscript.org

## Out of scope

- Dialectal Arabic (Egyptian, Gulf, Levantine) — not in training data
- Classical Arabic poetry — different conventions

## Metrics

- DER (Diacritic Error Rate) on held-out set
- Target: ≤ 5%
- p95 inference latency: ≤ 30ms per word

## Ethical considerations

This model reproduces biases in its training data. Tashkeela++ is
heavily Quranic + religious text; diacritization choices on secular
text may differ from speaker expectations.
